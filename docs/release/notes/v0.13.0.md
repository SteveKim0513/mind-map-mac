# v0.13.0 — 2026-09-03

보드(무드보드) — 세 번째 파일 타입 + 태그 바(색상 태그 범례).

## 새 기능

- **보드(무드보드).** 마인드맵·노트와 나란한 세 번째 파일 타입(`.board`)이 생겼다. 스티키노트를 자유롭게 배치하고 화살표로 연결하는 무드보드다. 스티키를 선택하고 방향키를 누르면 그 방향으로 이어서 확장되고, "정리" 버튼으로 연결된 하위 트리를 한 번에 정돈할 수 있다. 화살표는 끝을 끌어 다른 스티키로 재연결하거나 짧은 라벨을 붙일 수 있고, 여러 스티키를 함께 선택해 색·모양·정렬·서식을 일괄 편집할 수 있다. 스티키를 마인드맵 노드나 노트에 연동해두면 카드 안 칩을 눌러 바로 그리로 이동한다.
- **태그 바(색상 태그 범례).** 경로 바 바로 아래에서 이 맵(또는 보드)에 쓰인 색상 태그에 이름을 붙이고 칩으로 표시하며, 클릭하면 그 색만 필터링해 볼 수 있다. 하단 캔버스 툴바의 기존 색 점 필터를 대체한다.
