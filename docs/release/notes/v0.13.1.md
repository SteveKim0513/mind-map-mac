# v0.13.1 — 2026-09-03

보드를 앱 전역에서 마인드맵·노트와 동등하게 반영 + 전체 검색 확장.

## 버그 수정

- **홈 화면·파일 메뉴·⌘K에 "새 보드"가 없었다.** 사이드바에서만 보드를 만들 수 있었던 문제를 고쳐, 빈 워크스페이스 첫 화면·파일 메뉴·⌘K 명령 팔레트에서도 보드를 바로 만들 수 있다.
- **Quick Open·최근 파일·즐겨찾기·휴지통·경로 바에서 보드가 잘못 표시됐다.** 파일 이름에 ".board" 확장자가 그대로 남거나 마인드맵 아이콘으로 오분류되던 문제를 고쳤다.
- **전체 검색(⌘⇧F)이 보드를 건너뛰었다.** 이제 모든 보드의 스티키 텍스트도 검색되고, 결과를 고르면 그 보드를 열어 스티키를 선택 + 화면 중앙으로 이동한다.
