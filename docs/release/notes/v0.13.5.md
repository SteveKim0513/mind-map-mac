# v0.13.5 — 2026-09-07

## 새 기능

- **보드의 사진에도 색·연동(노드/노트/외부 링크)을 추가했습니다.** 스티키 노트가 갖고 있던 색 지정과 "연동"(마인드맵 노드, 노트, 외부 링크 연결)을 사진 요소에도 그대로 확장했습니다. 사진을 선택하면 스티키와 같은 플로팅 메뉴가 뜨고, 색을 고르면 사진 자체를 가리지 않도록 테두리에 아주 얇게 표시됩니다(기본값은 스티키와 동일한 노란색). 카드 안(사진은 바로 아래) 칩을 누르면 그 노드·노트로 이동하거나 링크를 새 창으로 엽니다.
