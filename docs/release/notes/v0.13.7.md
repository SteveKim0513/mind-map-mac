# v0.13.7 — 2026-09-07

## 새 기능

- **"정리"가 진짜 관계도를 훨씬 잘 정돈해줘요.** 여러 스티키가 서로 얽혀 있어도, 화살표 교차를 최소화하는 전문 그래프 레이아웃 엔진(elkjs)으로 재배치돼요. 스티키 하나가 여러 개와 동시에 연결돼 있어도 그 관계를 빠짐없이 반영해요.

## 버그 수정

- **"정리"가 다중 연결(교차 관계)이 있는 관계도에서 화살표가 서로 겹치고 꼬이던 문제.** 이전엔 "여분의" 연결이 재배치 계산에서 아예 빠졌었어요.

## 주의

- "정리"를 처음 누르면(앱 시작 시가 아니라) 레이아웃 엔진을 한 번 불러오는 짧은 지연이 있을 수 있어요.
