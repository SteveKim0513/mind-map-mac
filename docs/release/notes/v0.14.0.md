# v0.14.0 — 2026-09-21

## 새 기능

- **공유 폴더**: 폴더를 마우스 오른쪽 버튼으로 눌러 "공유 폴더로 만들기"를 하면 초대 코드가 생기고, 다른 사람이 사이드바의 참가 버튼(또는 파일 메뉴 "공유 폴더 참가…")에 코드를 넣어 같은 폴더를 함께 써요. 공유 설정에서 새 코드, 참가자 확인, 내보내기, 나가기를 할 수 있어요.
- **노트 동시 편집**: 같은 노트를 여러 명이 동시에 써도 자동으로 합쳐지고, 상대의 커서와 이름이 보여요. 오프라인에서도 계속 쓸 수 있어요.
- **맵·보드는 만든 사람만 편집, 나머지는 보기 전용**: 소유자가 고치면 참가자 화면에 바로 반영돼요.
- **코멘트와 즉시 알림**: 보기 전용인 맵·보드의 노드·스티키를 우클릭해 코멘트를 남기고, 노트는 위쪽 "코멘트" 버튼으로 남겨요. 코멘트가 달리면 바로 알림이 떠요.
- **알림 센터**: 사이드바 맨 아래 알림 버튼에서 받은 알림을 모아 보고 읽음/안 읽음을 표시해요.
- **보드 노트 링크가 노트 이름을 바꿔도 유지돼요.**

## 개선

- 링크는 웹 주소(http·https)와 메일(mailto)만 열려요(다른 사람이 공유한 파일의 링크가 다른 프로그램을 마음대로 열지 못하게 하기 위해서예요).
- 공유 연결과 화면 오류가 앱 로그 파일에 남아 문제 진단이 쉬워졌어요(문서 내용·초대 코드는 기록하지 않아요).

## 버그 수정

- 이전엔 보드의 노트 링크가 노트 이름을 바꾸면 조용히 끊겼어요 — 이제 노트 id로 찾아가요.

## 알려진 이슈

- 공유 폴더의 노트에는 아직 이미지를 넣을 수 없어요.
- 처음 참가한 사람은 다른 참가자가 한 명 이상 접속해 있을 때 기존 내용을 받아요.
- 전화·문자 링크와 다른 앱을 여는 링크(딥링크)는 열리지 않아요.
- 릴리즈 CI에 공유 서버 빌드가 추가된 첫 배포예요 — CI 결과를 확인해야 해요.
