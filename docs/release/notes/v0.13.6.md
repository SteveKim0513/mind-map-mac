# v0.13.6 — 2026-09-07

## 새 기능

- **화살표(커넥터) 색상 커스터마이즈.** 화살표를 선택하면 스티키와 같은 색 팔레트로 색을 지정할 수 있고, 화살촉도 항상 같은 색을 따라간다.

## 버그 수정

- **"정리"가 항상 오른쪽 열로만 재배치하던 문제.** 이제 각 가지가 처음 연결한 방향(상하좌우)을 그대로 따라가며 그 방향으로 계속 뻗어나간다 — 아래쪽으로 만든 구조를 정리해도 오른쪽으로 튀지 않는다.
- **화살촉이 선의 hover/선택/커스텀 색을 따라가지 않던 불일치.**
- **hover 강조가 커스텀 색을 지우던 문제.** 이제 색은 유지한 채 강조만 된다.
