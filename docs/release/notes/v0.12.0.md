# v0.12.0 — 2026-09-01

파일 경로 가시성(경로 바)과 캔버스 다중 선택(러버밴드) — 두 가지 진짜 새 기능 + 사이드바 폴더 클릭 UX 정리.

## 새 기능

- **경로 바(Path Bar).** 탭 바로 아래 Finder 스타일 경로 표시줄이 생겼다. 이름이 같은 파일이 서로 다른 폴더에 있어도 지금 열려 있는 게 어느 것인지 한눈에 구분할 수 있다. 폴더 세그먼트를 클릭하면 사이드바에서 바로 그 위치를 보여준다. 경로가 길면(폴더 3단계 이상) 가운데가 `…`으로 접히고, 클릭하면 전체 경로가 인라인으로 펼쳐진다.
- **캔버스 러버밴드(박스) 다중 선택.** `Shift+드래그`로 캔버스에 박스를 그리면 박스에 걸치는 노드가 모두 선택된다(기존 선택과 합쳐짐). 모디파이어 없는 드래그는 기존 그대로 화면 이동(pan)만 하므로 기존 제스처와 충돌하지 않는다.

## 개선

- **사이드바 폴더 클릭이 더 이상 펼침 상태를 건드리지 않는다.** 새 폴더·새 노트를 만들 대상 폴더를 고르려고 클릭하면 그 폴더가 접혀버리던 불편을 없앴다. 펼치기/접기는 왼쪽 화살표 전용, 행 클릭은 선택 전용(+ 진행 중이던 ⌘다중선택 해제 — 파일 클릭과 동작을 통일).
