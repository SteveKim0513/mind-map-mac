# v0.14.1 — 2026-10-29

## 새 기능

- **검색한 곳으로 바로 이동**: 전체 검색(⌘⇧F)에서 노트를 고르면 본문에서 검색어가 모두 강조되고 첫 위치로 스크롤돼요. 오른쪽 위 찾기 바에서 Enter·↓로 다음, ⇧Enter·↑로 이전 위치로 가고, Esc로 닫으면 그 자리에서 바로 이어 쓸 수 있어요.
- **노트 안에서 찾기(⌘F)**: 노트에서 ⌘F를 누르면 이 노트 안에서 찾아요. 전체 검색은 ⌘⇧F예요.
- **맵 검색 이어 보기**: 전체 검색에서 마인드맵 노드를 고르면 맵 찾기 바가 검색어와 함께 열려, Enter로 같은 맵의 다음 일치 노드로 넘어가요.

## 개선

- 노트의 링크를 클릭하면 바로 브라우저로 열려요. 링크에 마우스를 올리면 실제 주소가 보여요.
- 노트 본문 아래 빈 공간을 누르면 커서가 문서 맨 끝에 놓여요.

## 버그 수정

- 접힌 가지 아래 노드로 이동하면 화면에 안 보이던 문제 — 이제 가지를 펼쳐 보여 줘요.
- 맵 찾기 바를 연 채 노드를 고치면 첫 번째 일치로 튀던 문제.

## 알려진 이슈

- 이미지가 많은 노트에서는 이미지가 늦게 뜨면서 첫 일치 위치가 조금 밀릴 수 있어요.
- 보드에는 아직 안에서 찾기가 없어요(스티키로 이동은 돼요).
