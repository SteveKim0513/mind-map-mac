# v0.13.2 — 2026-09-07

## 새 기능

- **보드 스티키에 외부 링크(URL) 연결.** 노드 연결·노트 연결에 이어 세 번째 연동 옵션. 카드의 칩을 누르면 브라우저에서 바로 열린다.
- **보드 빈 캔버스 더블클릭 → 스티키 생성.** 툴바를 거치지 않고 원하는 자리에 바로 만들 수 있다.

## 개선

- **연결 포인트(앵커) 크기·discoverability.** 10px→14px로 확대, 항상 마운트한 채 기본 상태는 흐리게(hover·선택 시에만 진해지고 커짐)해 화살표를 어디서 이을 수 있는지 미리 알 수 있다.
- **색 필터가 마인드맵처럼 그리드로 재배치.** 이전엔 흐리게 dim만 했으나, 이제 일치하는 카드만 남기고 그리드로 재배치(뷰 전용, 문서 좌표는 불변).

## 버그 수정

- **화살표가 스티키 위로 그려지던 z-order.** 연결선은 항상 스티키 뒤에, 라벨·재배선 손잡이는 앞에 그리도록 렌더 순서를 분리.
- **드래그 중 화살표 경로의 불연속 팝(pop).** `routeWaypoints()`의 정렬-직선 특수 케이스를 제거해 연속적으로 변형되도록 수정.
- **노드/노트 연결 피커에서 항목을 클릭해도 연결이 안 되던 버그.** `pointerdown`이 캔버스의 `setPointerCapture`와 충돌하던 근본 원인을 수정.
- **피커가 열린 채 스크롤하면 뒤 보드도 같이 팬되던 문제.**
- **분할 화면에서 새 스티키/이미지가 안 보이는 곳에 생기던 문제.** 캔버스 자기 컨테이너 기준으로 스폰 위치 계산.
