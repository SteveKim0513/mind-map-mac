# v0.11.6 — 2026-07-26

겹친 화면의 "되돌아가기" 정비 — 사용자 보고(설정→최근 수정 복귀 불가)에서 출발해 동일 논리의 문제를 전수 감사로 찾아 오버레이 스택(ADR 0018)으로 한 번에 해소.

## 개선

- **겹쳐 연 화면의 한 단계 복귀.** 설정·최근 수정·사용 안내·휴지통 등 관리형 화면이 열린 순서대로 쌓이고, 닫기/Esc/배경 클릭은 맨 위 화면 하나만 닫아 이전 화면으로 돌아온다. 나중에 연 화면이 항상 위에 보인다(커맨드 팔레트로 다른 화면 위에 열어도 동일). 최근 수정·즐겨찾기에서 파일을 "열기"하면 겹친 화면이 모두 닫히고 바로 이동한다.

## 버그 수정

- **설정 → 최근 수정이 설정을 닫아버려 되돌아갈 수 없던 문제.** 이제 설정 위에 겹쳐 열리고 닫으면 설정으로 복귀.
- **설정 → 사용 안내에서 Esc 한 번에 두 화면이 동시에 닫히던 문제.** Esc는 사용 안내만 닫는다.
- **화면 위에서 커맨드 팔레트로 연 다른 화면이 아래에 깔리던 문제.** (예: 설정 위 ⌘K → 휴지통)

## 주의

- 업데이트 상태 팝업(다운로드 진행 등)은 스택 밖의 일시 표시라 기존 동작 그대로다 — ADR 0018에 기록.
