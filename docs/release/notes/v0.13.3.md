# v0.13.3 — 2026-09-07

## 새 기능

- **보드 실행 취소·다시 실행(⌘Z/⌘⇧Z).** 스티키를 옮기거나 크기를 바꾸는 것도 드래그 한 번이 한 단계로 취급된다.
- **노드/노트 ↔ 보드 역참조.** 스티키를 마인드맵 노드·노트에 연동하면, 이제 그 노드·노트 쪽에도 "보드에서 참조됨" 칩이 떠서 바로 그 보드로 돌아갈 수 있다.

## 버그 수정

- **연동 검색창·외부 링크 입력창에서 백스페이스를 누르면 스티키가 통째로 삭제되던 버그.** 캔버스의 전역 삭제 단축키로 키 입력이 새어나가던 것을 막았다.
- **이미 연결된 두 스티키 사이를 다시 드래그하면 화살표가 겹쳐 늘어나던 문제.** 기존 커넥터를 재사용(선택)하도록 수정, hover 시 강조 스타일도 추가.
- **긴 텍스트가 연동 칩 행과 겹쳐 보이던 문제.**
